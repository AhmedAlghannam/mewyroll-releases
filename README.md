# Mewyroll for Windows

Downloads for the Mewyroll Windows app: Mewyroll in its own window, with the
streaming server built in.

**[Download the latest version](../../releases/latest)**, then run
`Mewyroll-Setup-x.y.z.exe`.

- Windows may say the publisher is unknown (the installer isn't code-signed):
  **More info → Run anyway**.
- The app updates itself: when a new version is out, it downloads it in the
  background and switches to it the next time you open Mewyroll.

This repository only holds the installers.
